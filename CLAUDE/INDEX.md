### Starting a New Project
1. Read [CLAUDE.md](CLAUDE.md) for rules
2. Read [KILL.md](KILL.md) for restrictions
3. Choose domain: [frontend](frontend/README.md), [backend](backend/README.md), or [infrastructure](infrastructure/README.md)

### Reviewing Infrastructure Changes
1. Read [terraform-reviewer](.github/skills/terraform-reviewer/SKILL.md) skill
2. Use the checklist provided
3. Validate: `terraform fmt`, `terraform validate`

### Creating CI/CD Workflows
1. Read [github-actions](.github/skills/github-actions/SKILL.md) skill
2. Follow patterns for concurrency, permissions, secrets
3. Pin all action versions

### DevOps/SRE Work
1. Read [devops-engineer](.github/skills/devops-engineer/SKILL.md) skill
2. Follow workflow: Goal → Triage → Plan → Execute
3. Always verify impact before deploying

### Understanding Project Organization

2. Reference this INDEX.md as needed
3. Use [claude-guide.md](claude-guide.md) for quick lookups
